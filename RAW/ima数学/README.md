## ⚠️ 使用前必读：这份素材的三个固有缺陷

这不是孩子的卷子，是**外部教辅卷**。用它之前先认清三条边界。

### 缺陷一：答案侧 OCR 有公式错乱 —— 答案不可直接采信

实测「001（答案）」中出现：

| 原文（错乱） | 应为 |
|---|---|
| `BE两点的距离为 x` | `BE` 两点的距离（丢字） |
| `\frac{1}{2}D是AB中\frac{1}{2}` | 两处 `\frac{1}{2}` 粘连 |
| `\frac{β}{3}=\frac{EF}{AE}=\frac{x}{12-π}` | 分母被 OCR 成 `12-π`，实际是 `12-x` |

**题干侧干净，答案侧脏。** 所以：
- 题干可以直接引用
- **答案只作「解题思路参考」，绝不可作为 `answerKey` 入库**
- 真要用，必须逐条人工复算（走项目「核卷纪律」）

### 缺陷二：几何图形丢失，只剩顶点标签

拉下来的文本里图形是这样的：

```
![A\nB\nC\n](2/.../figure9dfba2c....png)
```

`A\nB\nC` 是图形上的**顶点文字标签**，图形本身在 ima 侧，**本地没有图片**。

⇒ **纯文本讲几何题不够**（与 `docs/试卷库建设/上海试卷采集-现状与阻塞.md` 第五节同一个结论）。
凡涉及图形，必须另配图，否则孩子看到的是一道没有图的题。

### 缺陷三：不是上海新教材口径的确认源

项目已有铁律：**教材类事实的信息源优先级是
教辅站 < 历年真题 < 孩子手上课本照片 < 学校/老师明确告知**。

本目录属「教辅站」级。⇒ **本目录不能用来确认教材章节、考纲、考点分布。**
2026-10-04 vectors 一事已因教辅站口径连错两次，方向相反。这个教训对本文档同样成立。
