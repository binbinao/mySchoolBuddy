2. 如图, 直线 $y = x + 3$ 与 x 轴、y 轴分别交于点 A、C, 经过 A、C 两点的抛物线 $y = ax^2 + bx + c$ 与 x 轴的负半轴上另一交点为 B, 且 $\tan \angle CBO = 3$.


(1)求该抛物线的解析式及抛物线的顶点D的坐标;

(2) 在该抛物线的对称轴上求一点 M，使得$\triangle ADM$的面积与$\triangle ABC$的面积相等，求 M 点的坐标；

(3) 若点 P 是射线 BD 上一点，且以点 P、A、B 为顶点的三角形与 $\triangle ABC$ 相似，求点 P 的坐标。

$$\begin{align*}\text{(1)}\text{解:} y=x+3\\ \text{令} x=0, y=3\\ \text{令} y=0, x=-3\\ \text{令} y=0, x=-3\\ \text{令} t m\angle C B D=\frac{a C}{0 B}=3\\ \therefore B(-1,0)\\ \text{抛物线:} y=a(x+3)(x+1)\\ \text{令} x=0, 3 a=3\quad a=1\\ \therefore y=x^2+4 x+3\\ \therefore D(-2,-1)\\ \text{解:} S_{\triangle A B C}=S_{\triangle A D M}=\frac{1}{2} x 2 x 3=3\\ \therefore\frac{1}{2}\cdot D M-1=3\\ \therefore DM=6\\ \therefore M(-2,5)\text{或}(-2,-7)\end{align*}$$

$$\begin{align*}\&\text{(3)}\text{解:} B(-1,0) D(-2,-1)\\ \&\text{直线BD:} y=x+1\\ \&\text{设上} p(m, m+1)\\ \& A B=2 A C=3\sqrt{2}\\ &\text{当}\triangle C A B\backsim\triangle A B p\text{时}\\ &\therefore\frac{B P}{A B}=\frac{A B}{C A}\\ &\therefore B P=\frac{A B^2}{A C}=\frac{4}{3\sqrt{2}}=\frac{2\sqrt{2}}{3}\\ &\therefore B P^2=(m+1)^2+\frac{4}{3}=\frac{8}{9}\\ &\therefore m=-\frac{5}{3}\text{或} m=-\frac{1}{3}>-2\text{(含)}\\ &\therefore P\left(-\frac{5}{3},-\frac{3}{2}\right)\end{align*}$$
