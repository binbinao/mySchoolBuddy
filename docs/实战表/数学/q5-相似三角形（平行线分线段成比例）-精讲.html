题干拆成 5 个已知

题干说的翻译过来
点 E、D、F 分别在边 AB、BC、AC 上E 在 AB，D 在 BC，F 在 AC。三个点别放错边——D 是唯一在 BC 上的那个，它决定了后面两次传递的公共顶点
DE ∥ AC这条平行线推出 BE/BA = BD/BC：AB 上的分比传给 BC，公共顶点是 B
DF ∥ AB这条平行线推出 CD/CB = CF/CA：BC 上的分比传给 AC，公共顶点是 C
AE : EB = 3 : 2全题唯一的数值来源。注意它给的是 AB 上的分比，不是 BE 与整体的关系
AF : FC 的值是求 AC 这条边上 AF 与 FC 的比，顺序不能反：先 AF，后 FC
最容易漏的是第 4 条。
它给的是 AB 上的比，你要的是 AC 上的比——中间隔着 两次平行线传递 + 一次换边补数，不是一步能到的。
而第 5 条的问法里还埋了第二道关：「AF:FC」是有顺序的，写成 FC:AF 就变成了另一个数。你栽的正是这一行。

读原卷的一个说明：这份卷面上红笔既用于他自己的草稿演算，也用于老师批改，所以个别笔迹归属只能按位置判断。能确定的是——括号内黑笔的「A」是他填的，紧挨着的红笔「B」是批改；草图里的 AF=2cm、FC=3cm 与 AE:EB=3:2 两处标注是他解题时用的数据。

先说结论：知识你会，错在读题。
这一页的重点不是重学知识点，而是把「答案回读」这个动作练成本能。

他在图上得到的比例，恰好就是正确答案。
AF = 2cm、FC = 3cm 直接就是 AF : FC = 2 : 3——选 B。
也就是说：方法没问题，图形关系读对了，连最终比例都算对了。 错的只是最后那 0.5 秒的填答动作：把算出的比倒过来填了 A。
所以这道题不需要重学相似三角形。
怎么做到「具体长度」这一步的？（这一步也值得学）
他用的是设具体值的思路：既然 AE:EB = 3:2，就把 AB 取成 3+2 = 5（份）， 于是 AE = 3、EB = 2。
再往下两次平行线传递：
BE/BA = 2/5 （AB 上的分比） BD/BC = 2/5 （DE ∥ AC，公共顶点 B）
这时 FC 还不能直接得，要先把 BC 换到 DC：
DC/BC = 1 − 2/5 = 3/5 ← 换边要「取补」 CF/CA = 3/5 （DF ∥ AB，公共顶点 C） AF/AC = 1 − 3/5 = 2/5 ← 同样取补 AF : FC = 2/5 : 3/5 = 2 : 3
这个思路本身非常干净——比纯列比例式好上手。他只是没有把这条链子写成式子，而是直接在图上标了数。

错的那个数，是怎么来的？

不是算错，是把已经算对的数倒过来了。对照原卷就看得清楚：

他算出的他填的问题
AF = 2，FC = 32 : 3顺序与题目一致，正确
同一个 2 : 33 : 2写进括号时前后调了个位置，正好是 A 的值
他心里的： AF 是 2，FC 是 3 → 2 : 3 笔下的： 3 / 2 ← 分子分母互换了 而选项正好设了这个套： A = 3/2 ← 倒过来的 B = 2/3 ← 本来就对的
这道题的真正陷阱在选项设计上。
2/3 和 3/2 都在选项里。也就是说，你算对还是错，跟你会不会做这道题毫无关系—— 只取决于最后写答案时有没有回读题目问的顺序。
所以这道题把全部难度都压在了「填答动作」上。
零成本防错法（30 秒能养成）：
写答案前把问句念一遍：题目问的是「AF : FC」，那就先念 A 那条线段（AF），再念后一条（FC）。
念出来的是 2 : 3 才往下填。顺序和选项一比，答案自己就跳出来了。

还有第二个更隐蔽的坑（在草图阶段被绕过去了）

他用具体长度（2cm / 3cm）走完了全程，所以没有踩到下面这个坑：一旦题目改成纯比值形式，就必须做「取补」。

传 BC 上的分比： BD/BC = 2/5 下一步却要用 DC：DC/BC = 1 − 2/5 = 3/5 ← 忘了「1 减」就错 传 AC 上的分比： CF/CA = 3/5 下一步却要用 AF：AF/AC = 1 − 3/5 = 2/5 ← 同样要「1 减」

他这次因为在图上标了具体长度，把这两次「1 减」悄悄做掉了（5−2=3，5−3=2）。题目一变脸（改成比值），这个坑就会露出来。

3零跳跃分步讲解

一步一个动作，做完上一步再点下一步。不做完不许跳。★ 标的是他当时停下的位置。

1
画图：把三个点放对边
›

动作：画 △ABC，在 AB 上标 E，在 BC 上标 D，在 AC 上标 F，连 DE 和 DF。

依据：题干第一句「点 E、D、F 分别在边 AB、BC、AC 上」——「分别」是一一对应的硬约束。

D 在 BC 上，是这道题的枢纽。
两条平行线都以 D 为端点，所以两次传递都要经过 BC。D 放错边，整条链子就断了。

检验：对着题干念一遍——「E 在 AB、D 在 BC、F 在 AC」——图上是不是一模一样？

小试：D 点在哪条边上？
只写边名，三个字母
2
把 AE:EB 换成「占整条边的几分之几」
›

动作：题目给的是 AE:EB = 3:2，但平行线分线段用的是对整条边的比。换成 BE/BA：

AE:EB = 3:2 （分比） BA = AE + EB = 3 + 2 = 5 份 BE/BA = 2/5 （占整边的比）

依据：平行线分线段成比例的公式长这样：

DE ∥ AC ⇒ BE/BA = BD/BC DF ∥ AB ⇒ CD/CB = CF/CA

左边两个的分母都是整条边（BA、CB），所以必须先把 AE:EB 换算过去。

检验：BE 是 AB 的一部分，BE < BA，所以 2/5 < 1 ✓ 对得上。分数应该比 1 小，如果算出个大于 1 的，说明方向反了。

顺手记一条通用习惯：凡是题目给 a:b，而公式要 a/整体，就先算整体 = a + b。
沪教版这类题几乎每题都要用这一步。
3
第一次传递：AB → BC ★ 他靠具体长度走通了这一步
›

动作：用 DE ∥ AC，把 BE/BA 传给 BC 上：

BE/BA = BD/BC 2/5 = BD/BC BD/BC = 2/5

依据：DE ∥ AC ⟹ △BDE ∽ △BCA，公共顶点是 B。

检验：2/5 = 0.4，BD 是 BC 的一部分，BD < BC ✓

他这一步是对的。原卷上他在图里标了具体长度，等价于把 BC 取成 5 份，BD = 2——比例完全一致。
4
换边取补：BD/BC → DC/BC隐藏的坑
›

动作：下一步要用的是 DC，不是 BD。而 BD + DC = BC，所以：

BD/BC = 2/5 DC/BC = 1 − 2/5 = 3/5 ← 必须「1 减」

依据：D 在 BC 中间，所以 BD 和 DC 合起来才是 BC。既然 BD 占 2/5，剩下的 DC 就占 1 − 2/5。

检验：2/5 + 3/5 = 5/5 = 1 ✓ 两个加起来正好是整条边。这一步验一下就不会错。

这一步是这类题的第一个固定扣分点。
「换边必取补」——BD 传给 DC 要做 1 减，AF 传给 FC 也要做 1 减。
他这次因为在图上标了具体长度（5−2=3），把这一步悄悄做掉了，所以没暴露。题目一改成纯比值就会撞上。
小试：BD/BC = 2/5，那么 DC/BC = ?
先写那个「1 减」
5
第二次传递：BC → AC
›

动作：用 DF ∥ AB，把 CD/CB 传给 AC 上：

CD/CB = CF/CA 3/5 = CF/CA CF/CA = 3/5

依据：DF ∥ AB ⟹ △CDF ∽ △CAB，公共顶点是 C。

检验：3/5 = 0.6，CF < CA ✓

为什么这里能直接传、不用取补？
因为这一步的起点 CD/CB 和终点 CF/CA 本来就是同一段，没换边。
规律：只有「BD→DC」「AF→FC」这种同一条边上换段的才要取补。
6
再取补，换回题目要的 AF ★ 你的断点在这附近
›
★ 前五步他都做对了。断点就在「最后交答案」这一下。

动作：题目问的是 AF，手上是 CF，再取一次补：

CF/CA = 3/5 AF/AC = 1 − 3/5 = 2/5 ← 又一次「1 减」 现在把同分母去掉，得到 AF:FC： AF/AC = 2/5 → AF 占 2 份 FC/AC = 3/5 → FC 占 3 份 所以 AF : FC = 2 : 3

依据：AF + FC = AC，同一条边分成两段；分母相同，比值就是份数之比。

这一步别用同分母算，直接数份数更快也更不容易错：
AC 一共 5 份，AF 拿 2 份、FC 拿 3 份 → AF : FC = 2 : 3。
顺序跟着题目走：题目问 AF 在前，就先写 2。

检验：2 + 3 = 5，和 AC 的总份数一致 ✓

7
★ 交答案前必做：把问句念一遍
›
★ 这就是你这道题唯一缺的动作。前面六步全对，栽在这里。

动作：笔停住准备填选项时，把题目的问句念出声：

念：「那么 AF : FC 的值是」 听到 AF → 对应 2 （AF = 2cm，他自己标的） 听到 FC → 对应 3 （FC = 3cm） 写成 2 : 3 → 选 B

依据：AF:FC 和 FC:AF 是两个不同的数，而选项把两个都给了，所以只有回读能分辨。

检验：把选好的答案代回问句读一遍——「AF 比 FC」读成 2 比 3，和选项 B 一致 ✓

最终答案
B（AF : FC = 2 : 3，即 2/3）
为什么这道题值得单独讲：
它的全部难度都压在最后 0.5 秒——前面全对，也照样丢分。
这是最值得练的题型：因为练的完全是「检查习惯」，而习惯一旦养成，所有选择题都受益。

练三题变式

先自己做，答案折叠着。做不出来再展开。
配比是固定的：改一个数值 → 换考点同手法 → 已知与所求对调。第三题不能省——很多人是「记住套路」不是「真懂」。

第 1 题（简单变式 · 只改一个数值）

图形、条件全都不变，只把最后问的比换个方向问：

在 △ABC 中，点 E、D、F 分别在边 AB、BC、AC 上，DE ∥ AC，DF ∥ AB，AE:EB = 3:2，那么 FC:AF 的值是（　）

A. 3/2　　B. 2/3　　C. 2/5　　D. 3/5

做完了，看思路
BE/BA = 2/(3+2) = 2/5 BD/BC = 2/5 （DE ∥ AC） DC/BC = 1 − 2/5 = 3/5 ← 取补 CF/CA = 3/5 （DF ∥ AB） AF/AC = 1 − 3/5 = 2/5 ← 取补 AF = 2 份，FC = 3 份 题目问 FC:AF，FC 在前 → 3 : 2 = 3/2 → 选 A

关键就是第 3 行：问句换了方向，答案也跟着换方向。
这题如果答案还写 B，那就是这道题的原错误又犯了一次——做之前先把问句念一遍。

第 2 题（同类型 · 换考点，同一手法）

平行关系不变，但把给出的分比换到另一条边上——考的是你换线的方向：

在 △ABC 中，点 E、D、F 分别在边 AB、BC、AC 上，DE ∥ AC，DF ∥ AB，AD:DB = 1:2，那么 AF:FC 的值是（　）

A. 1/2　　B. 2/1　　C. 1/3　　D. 2/3

注意题目条件换成了 AD:DB（D 在 BC 上），不是 AB 上的比。

做完了，看思路
条件直接给的是 BC 上的分比，不用先换算： BD/DC = 2/1 BD/BC = 2/(2+1) = 2/3 用 DF ∥ AB 传： CF/CA = CD/CB = 1/3 取补： AF/AC = 1 − 1/3 = 2/3 AF = 2 份，FC = 1 份 AF : FC = 2 : 1 = 2 → 选 B

这题比原题简单一步——因为 AD:DB 本身就落在 BC 上，第一步的「换算成整边比」直接省了。
但它同样要取补两次（DC 一次、AF 一次）。「换边必取补」这条规律在这里救了你。

第 3 题（问答对调 · 已知与所求互换）

这次反过来问。原题是「给 AE:EB，求 AF:FC」，这题是「给 AF:FC，反求 AE:EB」：

在 △ABC 中，点 E、D、F 分别在边 AB、BC、AC 上，DE ∥ AC，DF ∥ AB，AF:FC = 1:2，那么 AE:EB 的值是（　）

A. 1/2　　B. 2/1　　C. 1/3　　D. 3/1

做完了，看思路

推法一：原路走回去（推荐）

AF:FC = 1:2 → AF/AC = 1/3 取补： CF/CA = 1 − 1/3 = 2/3 DF∥AB 逆推： CD/CB = 2/3 取补： BD/BC = 1 − 2/3 = 1/3 DE∥AC 逆推： BE/BA = 1/3 取补： AE/AB = 1 − 1/3 = 2/3 AE = 2 份，EB = 1 份 AE : EB = 2 : 1 = 2 → 选 B

推法二：找对称关系（更快，但要能推出来）

原题：AE:EB = m:n → AF:FC = ? 反过来：AF:FC = p:q → AE:EB = ? 观察上面第 2 题：AD:DB = 1:2 → AF:FC = 2:1 可以验证出的一般关系是： AE:EB = m:n ⇒ AF:FC = n:m ← 正好「反比」 所以 AF:FC = 1:2 ⇒ AE:EB = 2:1 → 选 B
为什么第 3 题才是真正的考试题？
因为它逼你确认自己理解的是「关系」还是「套路」。
只会套原题流程的人，做这题会下意识把 1:2 又用一遍，写出 AE:EB = 1:2 选 A——正好是错的。
能做对这题，说明你真的知道为什么是反比，而不是背下了 3:2 → 2:3。

顺带一个反比关系的验证：原题 3:2 → 2:3，第 2 题 1:2 → 2:1，第 3 题 1:2 → 2:1，三次都吻合。

三题串起来看，考的是同一个能力：
① 第 1 题 → 提醒你答案跟着问句的方向变；
② 第 2 题 → 提醒你分比落在哪条边，就从哪条边开始传；
③ 第 3 题 → 考你知不知道「反比」这个关系。
但三题都逃不开同一个动作：交答案前把问句念一遍。

5. 什么情况下这个方法会失效？
最后一题必答。练的是方法的适用边界——知道什么时候不能硬套，比会用更重要。
想不出来？先看第 5 题的边界（这一题建议做完再看）

这套「平行线分线段成比例」能用的前提是：

前提不满足会怎样
必须是三角形没有第三个顶点，就没有公共顶点可传递，公式直接失效
必须有平行线没有平行就没有相似，比例关系无从谈起——这是最常见的前提缺失
点必须落在边上且在对应位置点跑到延长线上，相似仍成立但要改符号，直接套会出现负的长度
分比和所求必须落在同两条边上如果给的是 AE:EB 却问 AB 上的其他关系，要自己判断还需不需要传递
最需要警惕的一种失效：没有平行线。
题目里如果没有出现「∥」，就不要用这套公式。
比如若某天题目只说「DE 平分 ∠A」或「AD 是中线」，那是中位线定理的路子，比例形式不同，硬套会得到看着像样但错的答案。
一句话记住边界：
「三角形 + 平行线 + 点在对应边上」——三条全满足才用这套比例链。
少一条就停下来，换思路。
最后提醒一句：这道题你方法全对，只错了最后一步填答。
所以别再去刷相似三角形了——刷再多，填答动作没养成，下次照样丢分。
把这 5 题想清楚、把「念问句」变成习惯，比做 20 道同类题有用。
