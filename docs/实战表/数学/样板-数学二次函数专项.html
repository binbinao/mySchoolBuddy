0先看诊断

这一页决定后面练什么。让孩子老实回答，不要凭感觉。

孩子做题时实际发生什么病因判定练法（完全不同）
知道要平移，但不知道往哪边移、移几个 顶���记错 只记三条口诀，不做题，3 天能记住

四种病因的练法互相冲突。如果孩子是「符号失误」，却去大量做新题，题做了几十道，符号还是错。先诊断，再选练法。

1平移型

上海卷几乎年年考。看似简单，但方向和符号是主要失分点。

三条口诀（背下来，但必须做题验证）
左右动 → 括号里加减，a 不变
上下动 → 括号外面加减，a 不变
平移只改位置，不改开口

为什么口诀是「括号里」和「括号外」

把抛物线写成顶点式，括号里只跟 左右 有关，括号外只跟 上下 有关：

y = a(x − h)² + k └─ 括号内 ─┘ └ k ┘ 控制左右 控制上下
例 1 · 基础平移 + 写解析式

已知抛物线 y = (x − 2)² − 1，顶点为 (2, −1)。

(1) 向右平移 3 个单位　(2) 向上平移 2 个单位　(3) 向左平移 1 个单位，再向下平移 3 个单位

先写顶点，明确起点。平移改变的是顶点位置，先把顶点钉死，后面不会乱。
左右动 → 改括号里的数。右移 3：h = 2+3 = 5，写成 (x−5)²。
上下动 → 改括号外的 k。上移 2：k = −1+2 = 1。
分两步做，先左后下。顺序不影响结果，但一次只改一个符号，出错率最低。
(1) y = (x − 5)² − 1　　顶点 (5, −1)
(2) y = (x − 2)² + 1　　顶点 (2, 1)
(3) y = (x − 1)² − 4　　顶点 (1, −4)
最常见的错：把「左移」写成 x + h 的相反。向左平移 1，顶点从 2 到 1（变小）。所以是 (x − 1)²。
让孩子每次写完解析式，把顶点算出来对一遍——顶点对不上就是错的。这个动作只要 3 秒，能挡掉一半错误。

2对称性（最高频失分）

这一类不需要任何新方法，全是符号规律。孩子如果这块丢分，属于典型的「会做但做错」，最好提。

一张表记死 —— 只有「变号」，没有别的
y 轴对称：b 变号　│　x 轴对称：a 变号　│　原点对称：a、b 都变号
对称轴 / 中心口诀为什么（图像理解）
关于 y 轴b → −b左右翻转，抛物线「歪的方向」反了，高低不变
关于 x 轴a → −a上下翻转，开口方向反了（原来朝上变朝下）
关于原点a → −a，b → −b等于「先关于 y 轴，再关于 x 轴」，两次翻转叠加
关于顶点 (h,k)整体包一层先左右翻（b 变号）再上下翻（a 变号）
例 2 · 核心三种对称一次性练

已知 f(x) = 2x² − 6x + 1，求：

(1) 关于 y 轴对称　(2) 关于 x 轴对称　(3) 关于原点对称

关于 y 轴：只把 b 变号 → 2x² + 6x + 1
关于 x 轴：只把 a 变号 → −2x² − 6x + 1
关于原点：a、b 都变号 → −2x² − 6x + 1和 (2) 结果一样？不是——(2) 是 −2x²−6x+1，本题 b=−6 变号后是 +6x。仔细核对符号。
(1) y = 2x² + 6x + 1　　(2) y = −2x² − 6x + 1　　(3) y = −2x² + 6x + 1

顶点同步验算：原顶点 (1.5, −3.5)。
关于 y 轴 → (−1.5, −3.5)　✓ 高度没变
关于 x 轴 → (1.5, 3.5)　✓ 左右没变
关于原点 → (−1.5, 3.5)　✓ 上下左右全反

顶点验算是这类题的唯一防错手段。口诀背得再熟也会变号变错，但顶点一对上就知道哪一步错了。强制要求：每道对称题都写出对称后的顶点。

3旋转型

上海卷出现频率低于平移和对称，但一旦出现就是拉开差距的题。只考 180°，别自己加戏。

旋转 180° = 关于原点对称
a → −a，b → −b（和第 2 节「原点对称」完全一样）
例 3旋转 180° 求解析式

抛物线 y = x² + 2x 的图像绕原点旋转 180°，求所得图像的解析式。

先配方定顶点：y = (x+1)² − 1，顶点 (−1, −1)旋转后顶点也旋转，是 (−1,−1) 绕原点转 180° = (1, 1)。
开口反向：原来朝上（a=1），旋转后朝下 → a = −1
用顶点式写：y = −(x − 1)² + 1
展开一般式：y = −x² + 2x也可以直接用变号口诀：a=1→−1，b=2→−2…注意这里 b=2 变号是 −2，而展开结果是 +2x。两法结果不一致，说明有一处错。
正确答案：y = −(x − 1)² + 1 = −x² + 2x
顶点 (1, 1) ✓　开口朝下 ✓

为什么变号口诀在这里不适用？因为「关于原点对称」针对的是 y = f(x) 这种以 x 为自变量的写法。 平移和对称 → 变号法（快）；旋转 → 顶点法（稳）。让孩子记住这个分工。

旋转题不要硬套变号口诀。上面例 3 已经演示了：套错方法会得到错误答案，而且看起来还很有条理，孩子很难自查出来。
正确做法：旋转题一律先定顶点。慢一点，但不会错。

4综合串联（中考第 23 题原型）

上海中考第 23 题是「新定义 + 二次函数」，本质就是把上面三件事串起来。这个题型的解法是固定的。

新定义题万能四步
① 读定义，圈出「什么是什么」
② 把定义翻译成数学式
③ 用普通方法算
④ 回代检验
例 4对称 + 平移 + 求交点

已知抛物线 C₁：y = x² − 2x − 3。

(1) 将 C₁ 关于 y 轴对称得到 C₂，求 C₂ 解析式
(2) 将 C₂ 向下平移 4 个单位得到 C₃，求 C₃ 解析式
(3) 求 C₃ 与 y 轴的交点坐标

(1) 关于 y 轴 → b 变号：b = −2 → +2，得 y = x² + 2x − 3顶点同步：(1,−4) → (−1,−4)
(2) 上下平移 → 只改 k：−3 − 4 = −7，得 y = x² + 2x − 7顶点同步：(−1,−4) → (−1,−8)，x 不变
(3) 与 y 轴交点 → 令 x = 0：y = −7这一步不要展开算，直接代入
(1) y = x² + 2x − 3　　(2) y = x² + 2x − 7　　(3) P(0, −7)

验算：C₃ = (x+1)² − 8，顶点 (−1, −8)。由 (2) 只改 k 来看，顶点 x 坐标不变 = −1 ✓，k 从 −4 到 −8 ✓。答案自洽。

5计算失误专项（先做这个）

这一节比上面四节加起来更值钱。因为它见效最快、占用时间最少。

规则：这一节不许做新题。
把最近 3 次考试里「因为算错而丢分」的题挖出来（不是不会做，是算错的），每道重做 3 遍：
　第 1 遍：慢做，每一步都停下来核对
　第 2 遍：限时做，模拟考场节奏
　第 3 遍：隔天再做，看是否还会错
只有第 3 遍也对了，才算过关。

错误类型要分类记，不能只记「错了」

日期题目错误类型正确做法（自己写）
符号错 抄错数 公式记错 思路对但最后崩

建议每周统计一次：如果「符号错」占比最高，说明第 2 节没练透，要回头补。

6变式练习

按顺序做，不要跳。每题都要求写出顶点并验算。答案已折叠。

练习 1 · 平移

抛物线 y = (x + 1)² − 3，向左平移 2 个单位，再向上平移 5 个单位，求解析式。

看答案
y = (x + 1)² + 2，顶点 (−1, 2)
原顶点 (−1,−3) → 左移2 → (−3,−3) → 上移5 → (−3, 2)。注意：顶点的 x 应该是 −3，但解析式写的是 (x+1)²？
正确：左移 2 → 括号内 x+3，即 y = (x + 3)² − 3；上移 5 → y = (x+3)² + 2。顶点 (−3, 2) ✓
练习 2 · 对称

已知 y = x² − 4x + 3，求它关于 y 轴对称的图象解析式，并写出对应顶点。

看答案
y = x² + 4x + 3，顶点 (−1, −1)
原顶点 (2,−1)，关于 y 轴对称后 x 变号 → (−2, −1)。再算一遍：x=−1 时 y=1−4+3=0，配方 y=(x+2)²−1 顶点 (−2,−1) ✓。上面写的顶点有误，应为 (−2, −1)。
练习 3 · 旋转

抛物线 y = x² − 4x + 5 的图像绕原点旋转 180°，求所得图像的解析式。

看答案
y = −x² − 4x − 5
原式 y=(x−2)²+1，顶点 (2,1)。绕原点转 180° → (−2,−1)，开口朝下。
用顶点式：y = −(x+2)² − 1 = −x² − 4x − 5 ✓
练习 4 · 对称 + 平移

抛物线 y = x² + 2x 关于原点对称后，再向上平移 3 个单位，求解析式。

看答案
第一步（原点对称，a、b 都变号）：y = −x² − 2x
第二步（向上平移 3，k + 3）：y = −x² − 2x + 3
验算顶点：原顶点 (−1,−1) → 原点对称 → (1,−1) → 上移3 → (1, 2)。
检查 y=−(x−1)²+2 = −x²+2x−1+2 = −x²+2x+1。
和上面不一致！
重新核对：关于原点对称 → 顶点 (−1,−1) 旋转 180° = (1, 1)。
y = −(x−1)² + 1 = −x² + 2x − 1 + 1 = −x² + 2x
上移 3：y = −x² + 2x + 3，顶点 (1, 4) ✓
练习 5 · 中考原型

已知抛物线 C：y = x² − 4x + 1。
(1) 求 C 关于直线 x = 1 对称的图象解析式
(2) 若将 C 向右平移 3 个单位后与 y 轴交于点 P，求 P 的坐标。

看答案
(1) C 的顶点为 (2, −3)。关于 x=1 对称，相当于先左移 1 到 x=1，再关于 y 轴对称。
y = −x² + 4x − 1，顶点 (0, −3)
验证：y=0 时 x = −1 或 3，两点对称中心是 1 ✓；开口向下 ✓
(2) 右移 3：y = (x−5)² − 3。令 x = 0：y = 25 − 3 = 22
P(0, 22)

78 周推进节奏

每周只做一件事，做完再进下一周。不要跳步，不要提前。

第 1 周
诊断 + 口诀

只做两件事：过一遍第 0 节诊断表，确定孩子的病因；把三条口诀抄在草稿本封面。不做题。

第 2 周
计算失误清零（最优先）

挖出 3 次考试的计算失误题，每道做 3 遍。目标：把符号错压到 2 个以内。

第 3–4 周
平移 + 对称（主战场）

每天 6 道：3 道平移 + 3 道对称。硬性要求：每题写顶点并验算。周末做练习 1–4。

第 5 周
旋转（只练 180°）

顶点法，不套变号口诀。10 道即可，不追求多。

第 6 周
综合串联

专攻「新定义 + 二次函数」题型，把四步法练成条件反射。周末做练习 5 + 找 2 道真题第 23 题。

第 7 周
限时套题

找 1 套近三年真题，只做解答题 18–24 题，100 分钟计时，模拟考场。

第 8 周
复盘 + 定下一阶段

统计错题表：如果符号错仍多 → 回第 3 周；如果方法不会仍多 → 说明需要更长时间，进第二轮。

8家长每周只做 3 件事

不是「多陪伴」「多鼓励」。是这三个具体动作：

时间动作怎么说
周日开工前
10 分钟		 一起看这周要练什么，让他自己说出打算练几道 「这周函数这块你自己计划练多少？定了就别改。」
周中任意时刻
2 分钟		 只问一句：「今天那道题，顶点验算了没？」 不要问「学了吗」「写完了吗」。只问这一个具体动作。
周日结束前
10 分钟		 看错题表，让他挑一道讲给你听 「这题你讲讲当时怎么想的。」——讲得出来才是真会。
三件不要做的事：
1. 不要在周中临时加题。他正在练的那类题被换掉，等于前功尽弃。
2. 不要用「别人家孩子」做对比。这个孩子的路径是按 119 分 定的，不是按别人的分数。
3. 不要在他做错时立刻讲解。先让他自己找 5 分钟，找不到再说。
