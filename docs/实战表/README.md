# 实战表

> 每次深度诊断产出的**可执行作战表**。这是给孩子的具体材料，不是泛泛的学习建议。

## 什么是实战表

学情诊断告诉你"问题在哪"，实战表回答"接下来 8 周每天做什么"。两者必须配套——只诊断不给方案，孩子看完诊断依然不知道该干什么。

## 结构标准（参照 `数学/样板-数学二次函数专项.html`）

一份合格的实战表必须包含：

| 序号 | 板块 | 要求 |
|---|---|---|
| 0 | **先看诊断** | 开门见山说明这次专项针对什么问题、基于什么数据 |
| 1-N | **分型讲解** | 按题型/知识点分型，每型给出规范步骤 + 通俗解释 |
| — | **高频失分标记** | 明确标出哪几型是主要失分源，优先做 |
| N+1 | **计算失误专项** | 单独列出，针对性训练 |
| N+2 | **变式练习** | 验证是否真懂，不是原题重做 |
| N+3 | **周推进节奏** | 按周拆分，标注每周目标与检验标准 |
| N+4 | **家长每周只做 3 件事** | 具体到动作，禁止"多陪伴""提高兴趣"这类空话 |

## 编写纪律

- **不做题库机器**。表里每一道题都要说明"练什么、为什么练这一道"。
- **不盲目加题量**。先诊断再开方，避免题海。
- **难度对位**：给基础弱的孩子降低台阶而非降低目标；给学有余力的孩子加深度而非加题量。
- **不留白话**。"认真""仔细""多练"这类表述等于没说，必须换成可检验的动作。
- **HTML 单文件、内联 CSS、可直接双击打开给孩子做**，不依赖任何外部资源。
