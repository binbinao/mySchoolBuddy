# 实战表

> 每次深度诊断产出的**可执行作战表**。这是给孩子的具体材料，不是泛泛的学习建议。

## 什么是实战表

学情诊断告诉你"问题在哪"，实战表回答"接下来 8 周每天做什么"。两者必须配套——只诊断不给方案，孩子看完诊断依然不知道该干什么。

## 本目录放什么（与 `docs/整卷分析/` 的分工）

同一份卷子可能同时有两个页面，**这不是重复，是两个视角**：

| | `docs/实战表/<学科>/`（本目录） | `docs/整卷分析/` |
|---|---|---|
| **谁写** | `tools/build_skeletons.py` 生成骨架，AI 补全教学内容 | **纯人工**，生成器不写那个目录 |
| **视角** | 失分结构速览：分模块得分率 + 诊断结论 + 优先级 | 深度诊断：逐条失解剖 + 洞察 + 家长执行区 |
| **给谁看** | 孩子，按优先级刷 | 家长，判断方向对不对 |
| **更新时机** | 每次新卷入库自动重生成 | 人工判断后手动写 |

现存一对：`英语/2026-10-02-单元测-试卷拆解.html`（生成器，30K）与
`../整卷分析/2026-10-02-英语Unit1A-整卷分析.html`（人工，38K），同 `examId: e-20261002-01`。

**判据**：要「按优先级刷题」看本目录，要「这一阶段该怎么打」看整卷分析。
**两者引用的分数必须同源**——若对不上，**回原卷裁决，不要各自选边站**；
找出「两边都缺依据的那个共同前提」，显式记成 `null` + 说明为什么。

## 本目录的两类页面

| 类型 | 命名 | 来源 | 闸门 |
|---|---|---|---|
| **错题精讲页** | `q<题号>-<主题>-精讲.html` | `build_skeletons.py` | 五段范式 + 双向保真 |
| **试卷拆解页** | `<日期>-<卷名>-试卷拆解.html` | `build_skeletons.py` | `check_page_matches_data` |
| **专项作战表** | `主题-学科-专项.html` | 人工 | 结构标准见下 |

### 错题精讲页：五段范式（硬性）

① 原题 → ② 拆解 → ③ 零跳跃讲解 → ④ 三题变式 → ⑤ 迁移想五题。总时长 25-35 分钟。

| 段 | 硬性要求 |
|---|---|
| ① 原题 | **置顶**。题干**逐字**全文 + 限定词 `<span class="hl">` + 原卷照片（折叠）+ 题干拆解表 |
| ② 拆解 | 逐句翻译成条件，收尾点明「最容易漏的是第几条」 |
| ③ 零跳跃 | 一步一动作，★ 标断点，每步三件套（动作/依据/检验），末尾逐条件验证 |
| ④ 三题变式 | **配比固定**：简单变式 + 同类型 + **问答对调**。答案全 `<details>` |
| ⑤ 想五题 | 3-5 递进问，填空+即时判题，**末题必为「什么情况下这方法失效」** |

**问答对调不可省**——很多孩子是「记住套路」不是「真懂」。

**必备区块**：图形先行 → 已做对的部分 → 断点定位 → 分步法 → 坑的形态对照表 → 检验题 2 道（**答案折叠**）→ 复述检验 → 家长区（深色卡片，具体到分钟）。
**交互**：渐进解锁 · `localStorage` · 即时判题（**答错只提示不给答案**）· 复制按钮 · 重置需 `confirm`。

**文科适配**（语/英/史/政/地）：骨架不变。②标注答案在第几段 + 材料层次；③逐句解读文本（定义句/条件句/答案句/干扰句）；④换材料换设问；⑤题型识别 + 答题角度转换。

## 专项作战表：结构标准（参照 `数学/样板-数学二次函数专项.html`）

一份合格的作战表必须包含：

| 序号 | 板块 | 要求 |
|---|---|---|
| 0 | **先看诊断** | 开门见山说明这次专项针对什么问题、基于什么数据 |
| 1-N | **分型讲解** | 按题型/知识点分型，每型给出规范步骤 + 通俗解释 |
| — | **高频失分标记** | 明确标出哪几型是主要失分源，优先做 |
| N+1 | **计算失误专项** | 单独列出，针对性训练 |
| N+2 | **变式练习** | 验证是否真懂，不是原题重做 |
| N+3 | **周推进节奏** | 按周拆分，标注每周目标与检验标准 |
| N+4 | **家长每周只做 3 件事** | 具体到动作，禁止"多陪伴""提高兴趣"这类空话 |

## 命名规范

## 编写纪律

- **不做题库机器**。表里每一道题都要说明"练什么、为什么练这一道"。
- **不盲目加题量**。先诊断再开方，避免题海。
- **难度对位**：给基础弱的孩子降低台阶而非降低目标；给学有余力的孩子加深度而非加题量。
- **不留白话**。"认真""仔细""多练"这类表述等于没说，必须换成可检验的动作。
- **HTML 单文件、内联 CSS、可直接双击打开给孩子做**，不依赖任何外部资源。
- **图像只引 `RAW/`**（已入库的事实依据层），**绝不引 `data/_scans/`**（gitignore + 含个人信息，远端必断链）。交付前用真实浏览器验证 `img.naturalWidth > 0`。
- **答案默认折叠**——提前剧透等于没讲。
