### 来源 A：preview.21cnjy.com — 原卷扫描图（✅ 可用）

- **入口**：`https://mip.21cnjy.com/H/{docId}.shtml` → 提取 `preview.21cnjy.com` 图链
- **免登录直链**，860×1216 PNG
- **质量最高**：化学式下标（`Cu₂(OH)₂CO₃`）、几何图形、分数线全部保留，
  优于任何 HTML→文本方案
- **限制**：公开预览通常只放部分页，**不是完整原卷**。索引中 `pagesComplete` 一律标 `false`

## 三、三个抓取坑（已写进代码注释，勿重蹈）

### 坑 1：gzip 不解压 → 误判成「反爬」

**症状**：抓到的是二进制乱码，三个不同 docId 返回**完全相同的 7373 字节**。
**误判**：以为遇到反爬占位页，白排查三轮。
**真因**：不声明 `Accept-Encoding` 时服务端**仍会返回 gzip**，而 urllib **不会自动解压**。
**解法**：显式声明 `Accept-Encoding: gzip, deflate` + 手动 `gzip.decompress()`。

### 坑 2：整页 strip → 导航菜单伪装成正文

**症状**：生成 20 份「标题正确、正文全是『二一教育/网站首页/帮助中心』」的假 RAW，
还因为导航撑够长度而骗过校验。
**解法**：三步净化 —— 剥 `<head>` → 剥 `<script>/<style>` → 只留 ≥12 字成句行并去重。
校验器 `looks_like_exam()` 另加导航特征词密度上限。

### 坑 3：反爬挑战页冒充正文

**症状**：`「为保障您的访问安全，系统正在检测当前网络环境」` 39 字，
会被「正文过短」误判为普通抓取失败。
**规律**：并发 >3 或冷却不足即触发。
**解法**：
- 校验器显式拦截该挑战页（`looks_like_exam()` 已内建）
- 采集并发降到 **2**，请求间加 `random.uniform(1.2, 2.8)` 抖动
- 冷却期以**小时**计，不是分钟

## 四、解封后的执行路径

```bash
# 前提：确认 zujuan 已解封（单条测试返回真题干而非挑战页）
python3 tools/scan_zujuan_papers.py --subjects 数学 --pages 1 --text-workers 1

# 小批验证 → 再放开
python3 tools/scan_zujuan_papers.py --text-workers 2          # 全 9 科，每科 10 页
python3 tools/validate_schema.py                              # 必须 0 错误
```

**采集纪律**：
1. **先单条验证再批量** —— 反爬状态下批量只会产出「失败」噪声
2. 每套必须过 `looks_like_exam()` 才允许写 RAW，**标题对但正文空的一律拒收**
3. RAW 不可变：内容指纹（`bodySha`）不变就复用旧文件，避免 SHA-256 漂移触发红线
4. 分批提交，每批跑 `validate_schema.py`

## 五、诚实的局限

- **62 张原卷图不是完整原卷**，是平台公开预览页。完整版需付费或网盘
- **文本全文会丢公式排版**：几何图形、分数、上下标在 HTML→文本中丢失。
  讲题时**几何/物理/化学题必须配扫描图**，纯文本不够
- **2025 化学卷存在重复题**、**部分 2026 物理卷为 AI 拼凑题**（`trust: suspect`）——
  已记录在索引 `trustNote`，使用前必须复核
- 平台公开预览页数普遍不全，`pagesComplete` 一律 `false`，**不得当作完整原卷宣称**
