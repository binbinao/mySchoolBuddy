## 为什么必须建

知识点标注如果不落到具体章节，"九上 27.5 二次函数的简单应用"和"二次函数"在统计上是两个东西——前者能定位到具体页码、配套教辅、历年真题题型，后者只是一个模糊标签。

失分点热区的精度，取决于知识点标注的精度。

## 纪律

- **以孩子手上那本课本目录为准**，不同印次章节顺序可能有差异，录入时逐本核对。
- 教辅推荐同样按版本对位：沪教版配套教辅体系与全国通用教辅不同。
