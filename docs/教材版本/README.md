# 教材版本

> 沪教版（上海）九年级数学章节树与考点分布。

## 状态

🔴 **待建** —— 需要以孩子手上那本课本的实际目录为准逐章录入。

## 需要记录的内容

| 字段 | 说明 |
|---|---|
| 册次 | 九年级上册 / 下册 |
| 章 | 如"第 26 章 二次函数" |
| 节 | 如"26.1 二次函数的图象" |
| 核心考点 | 中考常考角度 |
| 新增/变化 | 2027 届新教材的增删（位似、三视图、投影为新增；向量、余切为删除） |

## 为什么必须建

知识点标注如果不落到具体章节，"九下 26.2 二次函数应用"和"二次函数"在统计上是两个东西——前者能定位到具体页码、配套教辅、历年真题题型，后者只是一个模糊标签。

失分点热区的精度，取决于知识点标注的精度。

## 纪律

- **以孩子手上那本课本目录为准**，不同印次章节顺序可能有差异，录入时逐本核对。
- 教辅推荐同样按版本对位：沪教版配套教辅体系与全国通用教辅不同。
