## 六、审核方法

**给你和孩子的妈妈各看一遍，重点看三件事：**

1. **命名能不能对上你们脑子里想的东西** —— 妈妈说「二次函数」，她指的是 M26-2 还是 M26-3？
2. **有没有漏掉她实际在学的** —— 校内进度可能超前/滞后于教材章节
3. **粒度对不对** —— 太细会累，太粗没法定位。建议每科 15-40 条

**审核结果请按这个格式回我：**

```
通过                          → 我把它固化成 data/resources/knowledge-tree.json 并加校验闸门
M26-2 改名为「二次函数图象与性质」 → 我按你的改
删掉 M31-5（尺规作图不考）        → 我删
漏了「概率与树状图」              → 我补
```

审核通过后我会：
1. 建 `data/resources/knowledge-tree.json`（**新增数据入口，同时在 `main()` 加 check** —— 铁律 2）
2. 加一条闸门：`point` 必须在词表内、章号必须与课本一致（**这是本词的闸门，防的就是「两个人各写各的」**）
3. 把 `data/wrong/` 现有两条的 `module`/`point` 归一到词表命名
