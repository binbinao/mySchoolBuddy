> 同一个闸门对两类数据行为不同 = 半个闸门。**修闸门时必须分别对 wrong 与 exam 各做一次回退法**，
> 只验一侧就会漏掉另一半——这正是本项目六轮里反复出现的同型教训。

改法：按任务 id 前缀路由（`wrong-` → data/wrong/，`exam-` → data/exams/），

| 位置 | 第五类 |

| **`README.md` schema 示例** | **时间不够** ❌ 缺「表达不规范」 |
