# mySchoolBuddy · 中学生学习助手

> 一个孩子 + 一位老教师（AI 形态）的错题与失分点作战室。
> 目标不是"题库机器"，而是把**失分结构**看清楚：分数丢在哪、为什么丢、下一周先补哪块。

上海某初三学生（2027 届 / 上海新教材第一届中考）长期跟踪项目。

---

## 这个仓库解决什么问题

孩子的现状诊断已经很清楚：**没有偏科，问题在于"会做的题在丢分"**。
语数英三科占全卷失分的 81%，而这些失分并不是不会，而是**概念不清、方法没想到、计算失误、审题表达不规范、时间分配失衡**这五类原因造成的。

所以本仓库的核心资产不是题目，而是**每一分丢在哪、属于哪一类病因**。

| 痛点 | 本仓库的解法 |
|---|---|
| 错题本只记题目，不记分数 | 错题 = 失分点，绑定分值与来源试卷 |
| 刷题很多，不知道哪块在崩 | 失分点热区图：按模块/知识点/病因排序 |
| 同一类题反复错 | 错因归类 + 复测排期，错了必须回炉 |
| 学了一堆，不知道补完没有 | 知识点掌握度表，变化可见 |

## 目录结构

```
mySchoolBuddy/
├── app/                      # 可运行应用（单文件、零依赖）
│   └── index.html            # 主程序：错题本 / 薄弱分析 / 任务打卡
│
├── docs/                     # 人读资产（方法、结论、方案）
│   ├── 实战表/               # 按学科分的专项作战表（HTML 可直接给孩子做）
│   │   └── 数学/
│   │       └── 样板-数学二次函数专项.html
│   ├── 方法论/               # 教法、复习节拍、错因分类标准
│   ├── 学情档案/             # 孩子的学情基线与阶段变化
│   └── 教材版本/             # 沪教版章节树与考点分布
│
├── data/                     # 机读数据（可版本化、可 diff、可回溯）
│   ├── exams/                # 试卷结构：卷面分值、模块划分、得分情况
│   ├── wrong/                # 错题（失分点）条目
│   └── progress/             # 掌握度与复测记录快照
│
└── tools/                    # 脚本（解析、统计、生成）
```

**为什么要这样分**：

- `app/` 与 `docs/` 分离 —— 程序会频繁改动，文档沉淀后很少动，避免每次改代码都把文档 diff 搅在一起。
- `data/` 独立成层 —— 这是本项目的**核心资产**，必须进 Git 才能追踪"这个月比上个月多丢了哪些分"。Git 天然擅长记录变化。
- `docs/实战表/` 与 `data/` 分离 —— 实战表是**结论**（经过诊断的判断），错题数据是**事实**（原始记录）。事实与结论分层，才不会让"我觉得他数学差"和"他数学丢了 27 分"混为一谈。

## 快速开始

### 用应用
直接用浏览器打开 `app/index.html`。零依赖、零构建、数据存浏览器 localStorage。
支持 JSON 导入导出，换设备或备份时用。

### 沉淀一份实战表
参照 `docs/实战表/数学/样板-数学二次函数专项.html` 的结构（诊断 → 分型 → 高频失分 → 8 周节奏 → 家长动作），新表放对应学科目录，文件名格式：

```
主题-学科-专项.html
例：相似三角形判定-数学-专项.html
```

## 数据模型（当前 v0，升级计划见下）

现有错题对象：

```json
{
  "id": "...",
  "title": "题目摘要",
  "sub": "数学",
  "point": "知识点",
  "cause": "概念不清 | 计算失误 | 审题错误 | 时间不够 | 方法没想到",
  "note": "复盘备注",
  "ts": 1696220000000
}
```

## Git 约定

- `main` 为稳定分支，功能开发走分支
- 数据文件（`data/`）用 JSON，明文可读，diff 友好
- 每次实战表新增 = 一次独立 commit，便于回溯"哪张表对应哪次诊断"

## 免责与边界

- 教材版本相关内容以**孩子手上那本课本目录**为准，版本会修订。
- 本仓库不承诺分数提升，只承诺把漏洞补上、把方法建起来。
- AI 不代做作业、不给可直接抄的答案，答案必须孩子自己想出来。
